## Review checklist (for the audit-trail review record in GXP-07)

- [ ] `audit.chain_verify` latest row: clean build OK; injected build broken at exactly the INJ-7 event.
- [ ] Audit INSERT row count per table equals the table row count (GXP-06 test).
- [ ] No CORRECTION rows without a reason and `supersedes_seq`.
- [ ] `audit.file_integrity`: all `matches = true` on a normal build.
- [ ] `integrity.alcoa_findings`: every finding explained by an injected problem, or raised as a deviation.
